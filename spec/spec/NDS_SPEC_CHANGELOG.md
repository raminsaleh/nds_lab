### Changed

- Node detection is no longer treated as swing-high/swing-low.
- 86% is treated as a context-specific reference zone, not a universal hard-coded trigger.
- ND is defined as Near Death, not Near Distance.
- GARCH is defined as the primary risk-management model.
- ATR is secondary fallback/benchmark.
- AI is restricted to error refinement and cannot replace NDS logic.
- Point 3 is defined as a decision area: rejection -> ND, break -> Flag continuation.
- Hook A and Hook B are separated.
